# 🎮 Tetris Game

A classic Tetris game implementation built with HTML, Visual Basic .NET, and JavaScript.

## 📋 Project Overview

This repository contains a fully functional Tetris game that brings the iconic puzzle gaming experience to life. The project combines multiple technologies to create an engaging and interactive gameplay experience.

## 🛠️ Technologies Used

- **HTML (81.4%)** - Game interface and layout
- **JavaScript (6.9%)** - Game logic and interactivity
- **Visual Basic .NET (11.7%)** - Backend logic and game engine components

## 🎯 Features

- Classic Tetris gameplay mechanics
- Interactive grid-based puzzle system
- Score tracking
- Real-time game updates
- Responsive design

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Visual Studio or Visual Studio Code (for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/efispi/TetrisGame.git
cd TetrisGame
```

2. Open the project in your preferred IDE or directly in a web browser

3. Run the game by opening the HTML file in your browser

## 🎮 How to Play

- **Arrow Keys** - Move tetromino pieces left and right
- **Up Arrow** - Rotate pieces
- **Down Arrow** - Move pieces down faster
- **Space** - Drop piece to bottom instantly
